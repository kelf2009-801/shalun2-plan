🗺 Фича 1. Геолокация — вкладка «Карта»

  • Карта: OpenStreetMap + MapTiler — 0₽, полностью на русском
  • Тумблер «Показывать меня на карте» — по умолчанию ВЫКЛ (приватность)
  • Маркер = аватар + позывной; зелёный = онлайн, серый = «был N мин назад»
  • Тап по маркеру → карточка + кнопка «Говорить лично»
  • Координаты раз в 60 сек через существующий foreground-service
  • ⚠ Android 14+: отдельное разрешение на фоновую геолокацию

🔗 Фича 2. Ссылки-приглашения

  • ✅ Уже есть: invite_code, вход по коду, регенерация
  • Кнопка «Пригласить» → ссылка /join/Ab3xK9 в WhatsApp/Telegram
  • Есть приложение → deep link сразу пускает в канал
  • Нет приложения → страница «Скачай Шалун» + APK
  • Плюшки: одноразовые, лимит человек, срок, отзыв ссылки

🖥 Фича 3. Диспетчерская веб-панель (B2B)

Первый клиент — автопарк автобусов Андрея. Бесплатный стенд → кейс → продажи.

  • Карта автопарка — все автобусы realtime, маркер = номер + позывной
  • Каналы = маршруты — диспетчер слушает и говорит из браузера (LiveKit JS SDK)
  • Водители — привязка «водитель = автобус = маршрут», добавление ссылкой
  • SOS — тревога водителя → красная вспышка + звук + автобус на карте

💰 Монетизация

  • Бесплатно: 1 канал, до 5 человек
  • Pro 99-149₽/мес: 50 человек, геолокация, SOS, ссылки
  • B2B 3-5к/мес за парк до 20 машин: диспетчерская
  • Конкуренты: Zello $2/юзера/мес (лагучий в РФ), Motorola 15к+ за рацию
  • Целевые: таксопарки, грузоперевозки, доставка, коммунальщики, охрана
  • Оплата: Telegram Stars или ЮKassa
